# Changelog

本文件记录 CheckMissingChapters 插件的所有版本变动。

## [1.3.0] - 2026-02-06

### 修复

- 修复缺失章节范围低报：当某卷实际起始章号大于期望起始时（如期望从1开始却从5开始），1-4 现在会被正确报告为缺失
- 修复占位符插入顺序倒置：多个缺失章节共享同一锚点时不再反序插入
- 修复 `bk.readfile()` 返回 bytes 时正则匹配崩溃，所有读取点统一做 UTF-8 解码

### 改进

- nav.xhtml 解析从正则匹配改为 ElementTree DOM 解析，支持 `<a><span>第十章</span></a>` 等嵌套标签结构
- XML 命名空间处理从正则替换改为 DOM 方式，避免误伤内容
- 中文数字转换 `cn2an_simple` 全面加固：
  - 无效输入返回 `None` 而非 `0`，防止误识别
  - 新增 `亿/億` 单位支持
  - 支持省略式写法：一百二→120、一千二→1200、一万二→12000、三百五→350
  - 正确处理零占位：三千零五→3005、一百零三→103、一万零一→10001
  - 单字 `十` 正确返回 10
- 所有 `except: pass` 改为具体异常类型（`re.error`、`json.JSONDecodeError`、`IOError` 等），错误信息输出到 Sigil 插件控制台
- 配置加载增加键白名单和类型校验，忽略非法配置项
- 检查报告新增"跳过条目"区域，显示因数字解析失败而被忽略的目录条目

## [1.2.0] - 2026-01-13

### 改进

- 重构：将单文件 `plugin.py` 拆分为多模块架构
  - `config.py` — 配置持久化与章节正则构建
  - `num_utils.py` — 全角/中文数字转换
  - `toc.py` — TOC 发现、解析与 nav.xhtml 修改
  - `report.py` — 核心检测逻辑与报告生成
  - `ui.py` — Qt 对话框与用户交互
  - `constants.py` — 共享常量
- 源码迁移至 `src/` 目录，新建 `docs/` 目录

## [1.1.0] - 2026-01-12

### 新增

- 正则安全性检查：编译失败时返回明确错误信息
- 扩展卷关键字支持，增加更多卷/部匹配词

### 改进

- 优化章节和卷正则处理逻辑
- 增强数字标准化与匹配

## [1.0.0] - 2026-01-09

### 新增

- 章节顺序异常检测（跳跃和倒退）
- 重复章节检测
- 详细的三段式分析报告（配置 → 目录分析 → 检查结果）
- 支持阿拉伯数字 / 中文小写 / 中文大写 / 混合模式
- 缺失章节检测与自动插入占位符（`【★缺失★】` 标记）
- 自动分段检测（章节号重置点）
- 分卷检测，支持自定义卷正则
- 编号模式选择：每卷从1开始 / 每卷从0开始 / 全书连续
- EPUB2/3 兼容（nav.xhtml / toc.ncx）
- 占位符插入与删除功能
- 配置保存与加载（config.json）

### 改进

- 完善 README 文档

## [0.2.0] - 2025-12-08

### 新增

- 初始版本
- 基础章节缺失检测
- Qt 界面（PyQt5 / PySide6 / PySide2 兼容）
- 中文数字与阿拉伯数字支持
